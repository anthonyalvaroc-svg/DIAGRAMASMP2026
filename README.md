# Generador de Esquemas Técnicos (SPAT / Perímetro / Torre)

Aplicación web estática en HTML5, CSS y JavaScript (`<canvas>`) para generar esquemas técnicos y descargarlos en formato PNG.

## Uso en GitHub Pages o Local
1. Reemplaza `index.html`, `styles.css` y `app.js` con los archivos de este paquete.
2. Mantén tu carpeta `img/` con los 8 archivos PNG (`1_torre_arbol.png` a `8_torre_arriostrada_edificio.png`).
3. Recarga la página con **Ctrl + F5** para limpiar la caché del navegador.
