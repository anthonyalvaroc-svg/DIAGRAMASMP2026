# Generador de Esquemas Técnicos (SPAT / Perímetro / Torre)

Aplicación web estática en HTML5, CSS y JavaScript (`<canvas>`) para generar esquemas técnicos y descargarlos en formato PNG:

1. **F12M - SPAT**: Diagrama de puesta a tierra con nombre del sitio ampliado (`32px`), pozos (`PT01`–`PT06`), telurómetro y mediciones.
2. **Esquema 1 - Perímetro**: Plano rectangular proporcional con nombre del sitio ampliado (`32px`), puerta de acceso, cotas exteriores en metros y coordenadas inclinadas en las 4 esquinas (`A`, `B`, `C`, `D`).
3. **Esquema 2 - Torre**: Elevación proporcional con las 8 imágenes originales en la carpeta `img/`, nombre del sitio ampliado (`32px`) y valores de altura integrados en tamaño y color acorde a las etiquetas de cada plano sin cubrir texto.
